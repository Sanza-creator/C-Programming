# C++ Programming Projects

Four C++ console applications covering core procedural programming concepts: input validation, control flow, arrays/loops, functions, and menu-driven program design.

## 1. Tech Store Purchase System
A point-of-sale style program for a gadget store: displays a catalogue, takes multiple item selections with quantities (with input validation), calculates the order subtotal, applies a 15% discount over a R2,000 threshold, and displays a formatted final total.

## 2. Sports Event Registration System
A registration system for a multi-event sports day: handles participant registration across several priced events, applies a group discount for 3+ participants registered under one name, and persists registration details to a file for record-keeping. Designed with a flowchart and algorithm before implementation.

## 3. Weekly Weather Monitoring Program
An array- and loop-driven program for a meteorological department: captures seven days of temperature readings, computes the weekly average, identifies the highest/lowest readings, and displays all recorded values in entry order for validation.

## 4. Fitness Membership Management System
A menu-driven gym membership system built around modular functions: account creation with a minimum starting credit, adding session credits, booking sessions against available credit (with insufficient-credit handling), checking remaining credits, and displaying full account details — looped until the user exits.

### Skills demonstrated
`C++` · `Functions & modular design` · `Arrays & loops` · `Input validation & error handling` · `File I/O` · `Menu-driven program structure`
